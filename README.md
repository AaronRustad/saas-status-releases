# SaaStatus

A macOS menu bar app that monitors SaaS service status. Supports macOS 13 or later, Apple Silicon and Intel.

This repository hosts signed, notarized app downloads. The source repository is private.

The first signed release is being prepared. Once it is published:

```bash
brew tap AaronRustad/tap
brew install --cask saastatus
open -a SaaStatus
```

Download ZIPs and checksums from [Releases](https://github.com/AaronRustad/saas-status-releases/releases).
